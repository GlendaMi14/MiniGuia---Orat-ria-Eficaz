# MiniGuia---Oratoria Eficaz
Caderno Temático: Oratória Eficaz: Guia prático com estratégias de oratória por nível

Este projeto aborda as principais estratégias de como desenvolver uma comunicação mais eficaz  e lidar com o nervosismo e enfrentar o medo de falar em público. O meu objetivo com este caderno é estudar, praticar, recomendar bons livros sobre o assunto e ajudar outras pessoas com este projeto, pois a oratória é um diferencial tanto para um profissional exelente quanto para situações mais simples.

Glossário:
-Linguagem corporal
-Nervosismo e o medo de falar em público
-Pilares da oratória
-Improviso

Alguns prompts que foram utilizados para gerar mapa-mental e relatórios com informações tirada das fontes:

1- Apresente exercícios e exemplos claros de como melhorar a oratória, faça em níveis como: Leve, intermediário e avançado, pois existem pessoas com diferentes problemas em relação a boa comunicação.

2- Crie um relatório que foque nas estratégias de melhoria de oratória, com dados, problemas que podem aparecer e como resolve-los de forma madura e sem prejudicar a transmissão da mensagem. Mostre também como a oratória não é presente só no mundo corporativo, mas é eficaz em diferentes lugares, público e contexto e nos diversos canais de transmissão de informação.
